# Dlicom Ad Revenue Simulator

A playful, mobile-first simulator for estimating creator ad revenue on Dlicom. Choose a content format, select a weekly posting rhythm, run the simulation, and download or copy a shareable result.

## Run locally

Requires Node.js 20+ and pnpm.

    pnpm install
    pnpm dev

Then open http://localhost:5173.

## Build

    pnpm run typecheck
    pnpm run build

Everything runs client-side in React state. No account or backend is required.
